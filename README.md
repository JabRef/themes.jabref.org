# themes.jabref.org

Themes for JabRef, its own one included; JabRef bundles every theme here that covers both color schemes.

- [index.md](index.md) is the site <https://themes.jabref.org/>: gallery, how to write a theme, migration from JabRef 5.x.
- [styleguide.md](styleguide.md) states the few rules behind the tokens. Read it before changing a theme.
