## Custom themes for JabRef

This directory contains various themes contributed by users. Themes that cover both color schemes in one file (via `@media (prefers-color-scheme: …)`) sit directly in this directory and work with any color scheme; the `DarkTheme` and `LightTheme` subfolders hold the themes that only cover one scheme, so select the matching color scheme in JabRef for those. Either way, open `File > Preferences > General > Appearance`, tick _Custom theme_ and select the CSS file.

The themes target JabRef 6 and later. Versions for JabRef 5.x are available [in the repository history](https://github.com/JabRef/themes.jabref.org/tree/0a139ff7da4ae356b293f81bd6a38659a7d7fc39/themes).

Keep in mind that user contributed themes might be distributed under different Open Source licences if you want to modify them.
